# トラブルシューティング

## 日本語化されない

以下を確認してください。

- 対応しているゲームバージョンか
- 対応しているMODバージョンか
- 導入手順に誤りがないか
- Release Noteに記載された対応ゲームビルドか

解決しない場合は、GitHub Issues から不具合報告をお願いします。

## ゲームが起動しない

MOD導入前の状態へ戻し、ゲームが正常に起動するか確認してください。

その上で、以下の情報を添えてIssueを作成してください。

- ゲームバージョン
- MODバージョン
- OS
- エラーメッセージまたはログ
- 発生手順

## 一部が英語のまま表示される

未翻訳箇所の可能性があります。

「未翻訳報告」Issueから報告をお願いします。

可能であればスクリーンショットを添付してください。

## ゲーム更新後に動かなくなった

対応確認が出るまでMODの利用を中止してください。ゲームファイルを推測で書き換えず、利用中のゲーム版とMOD版を添えて「不具合報告」Issueから報告してください。
