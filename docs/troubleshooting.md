# トラブルシューティング

## 日本語化されない

以下を確認してください。

- 対応しているゲームバージョンか
- 対応しているMODバージョンか
- 導入手順に誤りがないか

解決しない場合は、GitHub Issues から不具合報告をお願いします。

## ゲームが起動しない

MOD導入前の状態へ戻し、ゲームが正常に起動するか確認してください。

その上で、以下の情報を添えてIssueを作成してください。

- ゲームバージョン
- MODバージョン
- OS
- エラーメッセージ
- 発生手順

## 一部が英語のまま表示される

未翻訳箇所の可能性があります。

「未翻訳報告」Issueから報告をお願いします。

可能であればスクリーンショットを添付してください。
