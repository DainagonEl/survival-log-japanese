# 導入方法

現在、日本語化MODの初回リリース準備中です。公開済みの配布物はまだないため、現時点では導入できません。

正式なZIP構成、配置先、更新・削除・復元手順は、初回リリースの実機検証後にこのページへ掲載します。

## 想定環境

- Steam版 Survival Log
- Windows

対応するゲームビルドとMODバージョンは、各Release Noteで確認してください。

## 初回リリース後の確認事項

1. このリポジトリのGitHub ReleasesからZIPとSHA-256ファイルを取得する。
2. 公開されたSHA-256とダウンロードしたZIPが一致することを確認する。
3. ゲームを終了した状態で、そのReleaseに記載された手順だけを実行する。
4. 更新・削除・復元も同じReleaseの手順に従う。

具体的な配置操作は、配布形式が確定するまで掲載しません。

## 注意事項

ゲーム本体のアップデートにより、導入方法が変更される場合があります。

MOD導入前にゲームを終了し、必要に応じてゲームファイルとセーブデータのバックアップを取得してください。

ゲーム本体の更新後に対応確認が出ていない場合は、MODの導入・更新を行わないでください。
