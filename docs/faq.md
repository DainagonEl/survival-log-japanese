# FAQ

## これは公式の日本語版ですか？

いいえ。Survival Logの開発元・販売元とは関係のない、非公式の有志制作MODです。

## どこからダウンロードできますか？

初回リリース後は、このリポジトリのGitHub Releasesだけを正式な配布先とします。現在は初回リリース準備中で、公開済みの配布物はありません。

## 対応環境は？

Steam版・Windowsを対象に開発しています。対応するゲームビルドはリリースごとにRelease Noteへ記載します。

## すべて日本語になりますか？

初回リリースの翻訳範囲は未確定です。本編の会話、イベント、アイテム、チュートリアルなどには未翻訳箇所が残る見込みです。確認済みの範囲と既知の問題はRelease Noteへ記載します。

## ゲームが更新された直後も使えますか？

対応確認が出るまで使用を控えてください。ゲーム更新により、MODが停止したり正しく表示されなくなったりする可能性があります。

## 翻訳ミスや未翻訳を見つけました

GitHub Issuesの「翻訳改善提案」または「未翻訳報告」を利用してください。ゲーム版、MOD版、表示場所、原文・現在の訳、可能ならスクリーンショットがあると確認しやすくなります。

## MODが動きません

[トラブルシューティング](troubleshooting.md)を確認し、解決しなければ「不具合報告」Issueを作成してください。

## セーブデータへの影響はありますか？

初回リリース前のため、New Game以降を含む総合LQAは未完了です。配布版の確認結果と注意事項はRelease Noteで案内します。

## 開発用データやゲームの翻訳元データは公開されますか？

いいえ。このPublicリポジトリは利用者向け文書、Issue、Releaseだけを扱います。ゲーム由来データ、解析物、開発スクリプト、翻訳元データは公開成果物へ含めません。
