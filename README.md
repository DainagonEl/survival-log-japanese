# Survival Log 日本語化MOD

Survival Logを日本語でプレイするための非公式日本語化MODです。現在は初回リリースに向けて開発中で、公開済みの配布物はまだありません。

## 現在の対応状況

- Steam版・Windowsで開発中
- ゲームビルド`1.0.15369`で、メインメニュー・設定周辺の一部とキャラクター選択画面を確認済み
- 本編の会話、イベント、アイテム、チュートリアル、その他のゲーム内UIは未完了
- New Game以降の総合LQAは未実施

対応ゲーム版と翻訳範囲は、リリースごとのRelease Noteで明記します。

## ダウンロード

初回リリース後は[GitHub Releases](https://github.com/DainagonEl/survival-log-japanese/releases)からダウンロードできます。

> 現在は初回リリース準備中です。Release以外の場所から入手した非公式なファイルは使用しないでください。
