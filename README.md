# Survival Log 日本語化MOD

Steam版『Survival Log』を日本語で遊ぶための非公式MODです。

現在は初回ベータ版の公開準備中です。翻訳データの組み込みは完了しており、ゲーム内での最終確認を進めています。配布ファイルはまだ公開していません。

## 対応環境

- Windows版（Steam）
- Survival Log `1.0.15369`

対応状況はリリースごとに変わります。導入前に必ずRelease Noteをご確認ください。

## ダウンロード

公開後は[GitHub Releases](https://github.com/DainagonEl/survival-log-japanese/releases)からダウンロードできます。

Releases以外で配布されているファイルは、このプロジェクトの配布物ではありません。再配布や転載は認めていません。

## 導入方法

[導入・更新・削除の手順](docs/installation.md)をご覧ください。

## 不具合や翻訳の報告

[Issueフォーム](https://github.com/DainagonEl/survival-log-japanese/issues/new/choose)から報告してください。

- MODが動かない、表示が崩れる: 不具合報告
- 英語が残っている: 未翻訳報告
- 訳文を改善したい: 翻訳改善提案

よくある質問は[FAQ](docs/faq.md)、起動や表示の問題は[トラブルシューティング](docs/troubleshooting.md)にまとめています。
